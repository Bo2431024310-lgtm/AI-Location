# Makro AI Item Location

เว็บต้นแบบสำหรับค้นหาสินค้าและแสดงตำแหน่งชั้นวางภายในสาขา Makro ออกแบบให้ใช้งานง่ายทั้งบนคอมพิวเตอร์และมือถือ

## ฟีเจอร์ในเวอร์ชันแรก

- ค้นหาด้วยชื่อสินค้า แบรนด์ หรือหมวดหมู่
- ทางลัดสำหรับคำค้นยอดนิยม
- แสดงทางเดิน ชั้นวาง และสถานะสินค้า
- แผนผังร้านแบบโต้ตอบตามสินค้าที่เลือก
- รองรับหน้าจอมือถือ

> ข้อมูลสินค้า สต็อก สาขา และตำแหน่งในเวอร์ชันนี้เป็นข้อมูลตัวอย่าง

## เริ่มใช้งาน

ต้องใช้ Node.js 22.13 ขึ้นไป

```bash
npm install
npm run dev
```

จากนั้นเปิด URL ที่แสดงในหน้าต่างคำสั่ง

## โครงสร้างหลัก

- `app/page.tsx` — ข้อมูลสินค้า การค้นหา และส่วนติดต่อหลัก
- `app/globals.css` — รูปแบบหน้าตาและ responsive layout
- `app/layout.tsx` — ชื่อเว็บไซต์และ metadata

## แนวทางพัฒนาต่อ

1. เชื่อมต่อฐานข้อมูลสินค้าจริงและสต็อกแต่ละสาขา
2. เพิ่มระบบเลือกสาขาและแผนผังจริง
3. เพิ่มการค้นหาด้วยเสียงหรือสแกนบาร์โค้ด
4. เพิ่มระบบนำทางภายในอาคาร
